# DeskIt Creator (Floor Mapper)

SVG-based floor planner used by **Admin** to author logical `FloorDocument` layouts for DeskIt.

## Docs

- Product requirements: [../PRD.md](../PRD.md)
- Project overview & run instructions: [../README.md](../README.md)
- Technical geometry / schema: [document.md](./document.md)
- Feature checklist: [grid-ui/FEATURES.txt](./grid-ui/FEATURES.txt)

## Run

```bash
cd grid-ui
npm install
npm run dev
```

See the main [DeskIt README](../README.md) for stack, status, and how Creator connects to the Viewer/Manager app.
