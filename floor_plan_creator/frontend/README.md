# Floor Plan Creator

Web-based, grid-driven 2D floor plan editor.

## Architecture

- **Vector model** is the source of truth
- React-Konva is view/interaction only
- Matrices are compiled output

## Scripts

```bash
npm run dev
npm run typecheck
npm run lint
npm test
npm run build
```

## Stack

React, TypeScript, Vite, React-Konva, Redux Toolkit, Tailwind CSS, Vitest, Zod, Nanoid
